## 🚀 我的主力项目

<details>
<summary><b>🖥️ FaustLauncher — 桌面端</b></summary>

<br>

《边狱巴士》一体化启动器，为玩家提供汉化、美化、Mod 管理的一键启动流水线。

- **桌面架构** — pywebview + 原生前端替代 Electron，冷启动快、占用低；主窗口与子进程窗口分离
- **系统层与逆向** — 符号链接、原子替换、失败回滚；PE 解析、Unity 资源、内存 Hook 与偏移索引
- **完整分发** — PyInstaller 打包、独立资源包体系、多源回退与缓存降级的自动更新

</details>

<details>
<summary><b>🌐 FaustLauncherWeb — 云端后端</b></summary>

<br>

上述启动器的云端后端与官网，目前承载 **2600+ 用户、40+ Mod、21 万+ 次接口调用**。

- **无数据库后端** — 纯文本笔记按 key 寻址，换机器只需拷 data 目录；Bottle 单文件跑完整个 WSGI 应用
- **并发安全与加密** — 临时文件 + os.replace 原子写、锁内读改写；标准库 hmac/hashlib 实现 Cookie 签名与主页令牌加密
- **权限与部署** — 无密码登录、管理员双通道识别、用户 ID 默认打码；自写增量同步脚本走官方 API 部署

</details>

> 两个项目共享同一套哲学：**把复杂度留给自己，把轻便留给用户。**
